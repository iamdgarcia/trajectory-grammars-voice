# Review — r5_statistics_calibration (Statistical methodology)

## Summary
Section 4 defines a per-class one-sided SPRT over grammar-emission likelihood ratios, states a Trajectory Stopping Theorem (error control via Ville's inequality, expected decision time via Wald's identity), derives cost-asymmetric boundaries (Prop. 4.1), and positions TRACER as the fixed-sample instance. Section 5's metrics subsection reuses TRACER's EDS/detection-turn, adds a cost-weighted metric (eq:cost_weighted_latency), and commits to a calibration-then-check protocol (realized error ≤ ε; realized E[k_dec] ≤ K(ε,c)). The statistical core is sound and unusually honest (explicit assumptions, Ville-vs-Wald parametrization discussion, compliance escape excluded from scalar averages), but several definitions the evaluation protocol depends on are incomplete: ε, K(ε,c), the weighting π_θ, and the metric's length normalization.

## Score: 7/10
The theorem machinery is correct as far as I can verify from the displayed bounds and proof sketch: the Ville parametrization A=log(1/α), B=log β legitimately prices ever-crossing under continuous monitoring, the ±c overshoot slack in eq:times is conservatively valid (I checked the algebra of both displays), and the union bound over per-class error events is fine. The deduct of points is that the paper's own evaluation contract ("realised E[k_dec] must meet K(ε,c)") references a quantity that is never given an explicit formula, and the headline abstract claim is stated without the load-bearing assumptions. These are precision defects, fixable in a day, not structural ones.

## Mandatory revisions
1. **Define ε and the error-budget allocation** (§4.3, Thm 4.1 / eq:unconditional): "Pr[error] ≤ Σ_a(α_a+β_a) = ε" uses ε before it is defined as that sum. State ε := Σ_a(α_a+β_a) explicitly, and specify how the budget is allocated across classes (uniform? cost-proportional per Prop. 4.1?). The abstract's "expected decision time at most K(ε,c) at confidence 1−ε" must be qualified — the bound holds only under assumptions (i)–(iii), notably correct specification and conditional independence, which §4.3 itself admits "cannot be discharged."
2. **Give K(ε,c) an explicit definition** (§4.3 and §5.3 last paragraph): currently it is "the largest of the per-class bounds," but those bounds depend on α_a, β_a, μ₀, μ₁, c — not on (ε,c) alone. The calibration check in §5.3 is unrunnable as written. Provide the closed form, e.g., K = max_a [((1−β_a)A_a + β_aB_a + c)/μ₁^a] under the chosen budget allocation.
3. **Make eq:cost_weighted_latency well-defined** (§5.3): (a) w(k)=(L−k)/L uses L = realized dialogue length, unknown at decision time — state whether normalization uses realized L (oracle) or a horizon H, and acknowledge the length bias this shares with EDS; (b) correct-but-late decisions contribute exactly zero (c=0), so the metric is a cost-weighted error measure, not a latency measure — rename or add a latency term, since §5.6's dominance claim ("must dominate all five baselines under the cost-weighted metric at matched false-alarm budgets") is vacuous for a never-deciding rule only if the false-alarm matching is per-class; define the matching constraint; (c) specify π_θ under leave-one-campaign-out: fold-empirical prior shifts per fold, so say whether π is per-fold empirical, macro-averaged, or fixed.
4. **Calibration check has no power on rare classes; variant attachment unclear** (§5.3): "realised error ≤ ε" on a pooled test set will be dominated by the common class; with single-digit compliance-escape counts the check cannot reject. Require per-class and per-campaign realized-error reporting with exact binomial bounds, reliability diagrams per class, and CS coverage per turn. Also state which stopping variant (SPRT vs confidence sequence) each reported metric attaches to — and note that the CS variant (adopted per §4.3) has no K(ε,c) time bound, so E[k_dec] vs K should be reported as an empirical observation for CS, not a check.

## Optional suggestions
1. Report per-class decision-time quantiles (p50/p90/p99) in both turns and ms, not just pooled; §5.4 promises both currencies but per-class is where imbalance bites.
2. A Kaplan–Meier-style time-to-decision curve with censoring at k_term would display the eq:times claims better than scalar means.
3. In §5.3, cite that Wald–Wolfowitz optimality (cited in §4.3) applies to the classical SPRT, not the Ville variant you actually deploy.
4. Consider a pre-registered ε grid (e.g., ε ∈ {0.05, 0.10, 0.20}) for the synthetic benchmark so operating curves are comparable across folds.

## Questions for authors
1. Is w(k)=(L−k)/L normalized by realized final length, and how would the live monitor normalize without oracle L?
2. How is the ε budget split across (α_a, β_a), and does the split follow Prop. 4.1's cost ordering?
3. Do the SPRT and confidence-sequence operating curves share one emission model, and which variant produces the headline K(ε,c) numbers?
