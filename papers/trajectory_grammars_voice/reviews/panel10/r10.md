# Review — r1_sequential_analysis (Sequential-analysis expert)

## Summary
Section 4 defines an outcome-class posterior, a multi-class one-sided SPRT with Ville-parametrized boundaries (A=log 1/α, B=log β), a "Trajectory Stopping Theorem" with error and expected-time bounds, a cost-asymmetry proposition, and a TRACER-as-fixed-sample corollary. The error-control half (eq. `errors`) is correct: under assumption (i), e^{ℓ^a_k} and e^{−ℓ^a_k} are mean-one likelihood-ratio martingales under θ₀ and θ_a respectively, and Ville prices the ever-crossing events. However, the expected-time bounds (eq. `times`) are not correct as stated: the second display is false for the multi-class rule, the proof sketch's two-event decomposition ignores the third exit mode (k_term), and the ε budget omits cross-action misdeclarations.

## Score
**5/10.** The section is well-written and unusually honest about assumptions (the tool-call self-loop caveat in (iii) is exemplary), and the error bounds are sound. But this is a formal-contributions paper whose centerpiece theorem contains a false per-class time bound caused by the paper's own design choice ("declaring no action requires every class-wise ratio to fall below its lower boundary"), plus an invalid proof-sketch decomposition and an incomplete error budget. All are fixable with targeted edits; none destroys the contribution, but the theorem cannot stand as displayed.

## Mandatory revisions
1. **[P0] Per-class E[k_dec|θ₀] bound (eq. `times`, second display) is false under the multi-class rule.** Declaring θ₀ requires ∀a: ℓ^a ≤ B_a (Def. `rule`, eq. `kdec`), so k_dec is gated by the *slowest* class, while the bound is stated per class. Concrete counterexample respecting (i)–(iii): class a with μ₀^a=−0.462, B_a=log 0.1, A_a=log 20, c=1 gives bound ≈ 6.6 turns; add class b with step size δ≈0.14, μ₀^b=−0.01, B_b=log 0.01, so E[τ_b^down]≈460 turns. Under θ₀, E[k_dec]≈460 ≫ 6.6, violating the bound "for every action class a". Fix: state the θ₀-side bound as an aggregation over classes, e.g. E[k_dec|θ₀] ≤ min(E[k_term], Σ_a (|B_a|+c)/|μ₀^a|), and redefine K(ε,c) in eq. `unconditional` accordingly. The abstract's K(ε,c) claim survives in this corrected form.
2. **[P1] Proof sketch's decomposition is invalid: three exit modes, not two.** The claim "the stopped ratio is confined to [B_a−c, A_a+c]" holds only for the single-class rule; in the stated rule, on a k_term exit another class can block declare-θ₀ while ℓ^a plunges arbitrarily far below B_a−c (unbounded below under θ₀), and under θ_a a k_term exit carries values up to A_a rather than B_a. Hence the θ_a-side numerator (1−β_a)A_a+β_a B_a+c can understate achievable E[ℓ]=μ₁E[k] (mean overshoot near c with Pr[declare θ₀|θ_a]≪β_a). Fix: prove the clean envelope E[k_dec|θ_a] ≤ (A_a+c)/μ₁^a via a's own upper crossing (Wald + bounded increments, citing Lorden 1970 for finiteness/overshoot rigor), and handle the k_term mode explicitly via assumption (iii). Wald's identity also presupposes E[k_dec]<∞; note the truncation argument.
3. **[P1] The ε budget Σ_a(α_a+β_a) does not price cross-action misdeclarations (declare θ_b | θ_a, b≠a).** e^{ℓ^b} is not a martingale under θ_a, so Ville on ℓ^b alone cannot price this event; the pairwise LR martingale e^{ℓ^b−ℓ^a} yields Pr_{θ_a}[declare θ_b] ≤ α_b/α_a (nontrivial only when A_b>A_a), which is outside the stated budget. Since §4.5's cost model makes handoff-vs-escape confusion economically real, either add pairwise boundaries on ℓ^a−ℓ^j (standard multi-class SPRT) with a per-pair budget, or restate the ε guarantee as covering only {action|θ₀} and {θ₀|θ_a} errors, with a remark quantifying cross-action confusion.
4. **[P2, one-line fix] The supermartingale justification is wrong as written.** "exp(ℓ_k^a) … with expected increment e^{μ₀^a} ≤ 1" is false: under (i), E_{θ₀}[e^{Z_k}|F]=1 exactly (mean-one LR martingale); Jensen gives E[e^{Z}] ≥ e^{μ₀^a}, so the stated identity needs no independence and is not e^{μ₀^a}. Conditional independence (ii) is needed only for Wald, not for eq. `errors`. Correct the sketch's first sentence.

## Optional suggestions
1. As β_esc→0, B_esc→−∞ makes the ∀a-below-B event unsatisfiable: under θ₀ the rule then always runs to k_term. Consistent with "contained must be earned," but Proposition `asymmetric` should say so (its β_esc→0 term is then vacuous, not achieved).
2. State eq. `compose` with a high-probability quantile of k_dec; the theorem bounds a mean, a deadline is a quantile.
3. "Empirically [overshoots] are one turn at most" is an unsupported empirical claim; mark as design guidance or point to the protocol section.
4. Clarify that the cited Wald–Wolfowitz optimality applies to the classical two-sided SPRT, not to the wider-boundary three-exit rule of Def. `rule`.

## Questions for authors
1. Do you intend the θ₀-side time bound per class or as a max/sum over classes (see Mandatory 1)?
2. Should cross-action confusions (handoff declared when truth is compliance-escape) be priced inside ε, and if so via what pairwise parametrization?
3. Is c in assumption (ii) known a priori in the deployed monitor, and how is its estimate validated?
