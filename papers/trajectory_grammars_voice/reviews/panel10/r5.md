# Review — r6_presentation_notation (Writing / Notation / Presentation)

## Summary
This is an unusually well-written conceptual paper: clean one-sentence-per-line discipline, a consistent theorem/definition/remark apparatus, and figure captions that verifiably match their TikZ sources (Table 1 has exactly 10 transition types and fig_grammar draws all 10; fig_cycles draws 12 turn dots per panel and exactly three regression arcs for D=3). The abstract's claim ("expected decision time at most K(ε,c) turns at confidence 1−ε") matches Theorem thm:stopping exactly. Four notation defects remain: an ε overload, a self-inconsistent stopping figure, a T symbol collision, and mixed -ise/-ize spelling.

## Score: 8/10
Presentation is close to publication-ready. Structure flows logically (grammar → stopping → evaluation → intervention), every caption I checked matches its figure source, and prose discipline (one sentence per line) is maintained across all nine sections. The deductions are for notation hygiene: the same Greek letter ε doing duty as both the error budget of the headline theorem and two millisecond latencies in the same section, a stopping figure whose drawn geometry contradicts both its own on-canvas label and the theorem's assumptions, and a handful of symbol collisions that a notation pass would eliminate in an hour.

## Mandatory revisions
1. **ε overload (P1).** ε is the error budget in $K(\varepsilon,c)$ and "confidence $1-\varepsilon$" (abstract, eq:unconditional, §5.3), but ε_decide and ε_cease are *latencies* in §4.4, eq:compose, and the fig_stopping caption. Worse, §6.2 names the same cessation latency $\Delta_{\mathrm{cess}}$. Fix once: rename latencies to the existing λ family ($\lambda_{\mathrm{decide}}, \lambda_{\mathrm{cease}}$, matching $\lambda_{asr},\lambda_{lm},\lambda_{tool},\lambda_{tts}$ in Lemma lem:cyclebound) and use one name for the cessation component everywhere (sections/04_stopping.tex, figures/fig_stopping.tex caption, sections/06_intervention.tex §6.2).
2. **fig_stopping esc curve is inconsistent (P1).** The on-canvas label claims "$\ell_k^{esc}$ stays in $(B_{esc}, A_{esc})$", but neither boundary is drawn; worse, the curve sits at y ≈ +0.6–0.95, above the drawn $B_{hand}=-0.45$, so per Definition def:rule the joint θ₀-acceptance region (green band) is *never reachable* in the depicted conversation, and a positive-drift esc LLR under the benign class contradicts assumption (ii) ($\mu_0^a < 0$). The figure source itself contains a stale comment admitting the mismatch with different numbers. Redraw: draw $B_{esc}$ explicitly and put the esc curve drifting negative inside its corridor (figures/fig_stopping.tex).
3. **T symbol collision (P2, but the brief's core symbol).** $T$ is the terminal-class set (Def def:grammar, §4.1, §5.1) but §2.5 says "a dialogue of length $T$ contributes $T$ instances" (sections/02_background.tex, TRACER paragraph). Rename the length there to $L$. Relatedly, eq:cost_weighted_latency uses bare $L$ while the EDS formula three lines earlier uses $L_i$ — unify.
4. **-ise/-ize inconsistency (P2).** The paper is otherwise consistent BrE ("organised" §1, "summarises/formalisations/optimises/pseudonymised" §5, "characterise/idealisation" §8, "behaviour/rigour" §7), but §4 uses "parametrization" (×2) and "idealized" (×2), and §7 "unformalized" (×2). Notably "idealized" (§4) vs "idealisation" (§8) is the same word family in two spellings. Standardise to -ise.

## Optional suggestions
1. §3 hard-codes "Section~4 stops on it, Section~5 measures it, Section~6 acts on it" (also in def:run and rem:drift_trigger) while elsewhere \ref is used; convert to \ref to survive renumbering.
2. τ carries three meanings ($\tau_{resp}$ Lemma 1, $\tau_{human}\approx$200 ms §5.4, TRACER's $\tau=0.7788$). If $\tau_{resp}=\tau_{human}$ in the deployed cascade, say so and use one symbol; a short notation table would absorb this and findings 1/3.
3. θ class names render inconsistently: $\theta_{esc}$ vs $\theta = \text{compliance\_escape}$ (§5.1) vs "compliance-escape" prose. Pick subscript+prose convention.
4. Labels eq:kdec and rem:drift_trigger are never referenced; harmless, but prune or cite.

## Questions for authors
1. Is $\tau_{resp}$ (Lemma 1) numerically the same 200 ms as $\tau_{human}$ (§5.4) in the deployed cascade — i.e., what is the actual $k_{\mathrm{cyc}}$?
2. In fig_stopping, is the esc LLR intended to sit at +0.8 throughout a contained call? If it reflects the elevated-$\alpha_{esc}$ design, the figure needs $A_{esc}, B_{esc}$ drawn to show the corridor.
3. Will the promised HF synthetic benchmark publish the concrete per-class $(\alpha_a, \beta_a, c)$ matrix so readers can reproduce the boundary pairs of eq:boundaries?
